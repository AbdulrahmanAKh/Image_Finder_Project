Image retrieval finds existing images in a collection. It does not generate images or search the web.

Explore the notebook
  1. 1

    Start with an image

    Upload a photo or use a held-out sample. Keep the main subject near the center; CLIP uses a center crop.

  2. 2

    Turn pixels into meaning

    CLIP ViT-B/32 represents the image as 512 numbers. A processing animation follows the actual work.

  3. 3

    Find its visual neighbors

    Cosine similarity ranks a balanced 2,000-image gallery. Results may share subject, shape, color, or context.

Measured, with limits.

200 held-out queries, one per category. Relevance means sharing a dataset class. Sample images are outside the searchable gallery.

Evaluation loads with the collection.

This educational demo searches a small, low-resolution subset. It may return unrelated neighbors for unfamiliar subjects. CLIP has not been benchmarked against EfficientNetV2 here.
